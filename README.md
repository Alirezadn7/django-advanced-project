# Django Advanced Project

A backend development project built with Django and Docker, focused on learning scalable backend architecture and modern development workflows.

## Tech Stack

| Tech | Usage |
|------|-------|
| Python 3.12 | Core language |
| Django | Web framework |
| Docker & Docker Compose | Containerization |
| SQLite3 | Database |
| Pillow | Image upload support |

## Current Features

- **Blog Application** — Post model with image and author support
- **Custom User Authentication** — Email-based login using `AbstractBaseUser`
- **Image Upload Support** — Pillow integrated for ImageField
- **Dockerized Development Environment** — Docker & Docker Compose ready


## Goals

This project is being developed to improve backend engineering skills, API development knowledge, and production-ready architecture design.
